# Python_04 — Отправка запросов к LLM API

## Установка

```bash
python -m pip install -r requirements.txt
```

## Настройка ключа

1. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Откройте `.env` и вставьте свой реальный ключ вместо `ВАШ_СЕКРЕТНЫЙ_КЛЮЧ`:
   ```
   GIGACHAT_CREDENTIALS=реальный_ключ_от_GigaChat
   ```
3. Ключ получают в личном кабинете GigaChat API (после регистрации на сервисе).
   **Никогда не публикуйте `.env` и не делайте `git commit` этого файла** — он уже
   добавлен в `.gitignore`.

## Запуск

```bash
python lesson4.py
```

Появится меню:

```
1 — объяснить тему
2 — придумать идеи
3 — составить план
0 — выход
```

## Структура проекта

```
Python_04/
├── lesson4.py       # основная программа
├── .env.example     # шаблон для ключа (скопировать в .env)
├── .gitignore        # исключает .env, venv/, __pycache__/
└── requirements.txt  # зависимости (gigachat, python-dotenv)
```

## Возможные ошибки

| Ошибка | Причина |
|---|---|
| `ValueError: API-ключ не найден` | нет `.env` или пустая переменная |
| `SSLError` / ошибки соединения | нет интернета или проблема с сертификатами |
| `ModuleNotFoundError` | не установлены библиотеки — выполните `pip install -r requirements.txt` |
| Ошибка авторизации от сервиса | неверный или истёкший ключ |
